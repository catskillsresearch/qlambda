qλ language recap

Small call-by-value λ-calculus with three choices, plus emit for IBM Quantum Composer circuit instructions.

Goal

  • Keep the three choice operators (⊕p, ⊓, □).
  • Build exactly one Composer circuit per well-formed program.
  • Embed every instruction in a frozen Composer AST.
  • Clean denotational semantics (CP channels / instruments).
  • qλ ↔ Composer translations with preservation on a defined fragment.

1. Core qλ syntax

M, N ::= x
       | λx. M
       | M N
       | M ⊕p N
       | M ⊓ N
       | M □ N
       | emit I

First six forms = original Section 2 calculus. The quantum extension is emit I, appending one Composer instruction to the circuit under construction.

2. Readable surface syntax

let x ← M in N

Same as (λx. N) M. Ignored results: M ; N ≡ let _ ← M in N.

H q[0];
CX q[0] q[1];
measure q[0] -> c[0]

Sugar for nested emit of gate and measure instructions.

3. Circuit program wrapper

circuit q[2], c[2] in
  M
  • q[i] — opaque qubit handle (wire).
  • c[i] — classical bit handle.
  • State in a separate store; copying a handle aliases a wire, does not clone.
  • Well-formedness is a separate judgment (arity, scope, operands).

4. Composer instructions (type I)

I ::= Gate(g, parameters, qubits)
    | Measure(qubit, classical-bit)
    | Reset(qubit)
    | Store(classical-location, expression)
    | Barrier(qubits)
    | Delay(duration, qubits)
    | If(expression, circuit, circuit)
    | Switch(expression, cases)
    | For(range, circuit)
    | While(expression, circuit)
    | Box(label, circuit)
    | Modified(modifier, instruction)

Modifiers: ctrl, inv, pow.

5. Functional circuit construction

let bell =
  λa. λb.
    H a;
    CX a b
in

circuit q[2], c[2] in
  bell q[0] q[1];
  measure q[0] -> c[0];
  measure q[1] -> c[1]

CBV evaluation applies bell while accumulating emits; the Composer output has no λ.

6. Three choices (distinct compilation)

⊕p — ancilla coin: RY, measure, conditional branches (not H on terms).

⊓ — compiler scheduler picks one branch → one circuit.

□ — external classical selector chooses the branch.

7. Denotational semantics (sketch)

  • Gate → unitary channel (ρ ↦ U ρ U†)
  • Measure → instrument + classical update
  • Reset → CPTP reset
  • ⟦emit I⟧ = ⟦I⟧ on the Composer side
  • λ/application → recursive value domain; sequencing → bind
  • ωFVA (Chen–Kou–Lyu) for classical higher-order probability only; quantum = CP layer

8. Both directions

Composer → qλ:

emit I₁;
emit I₂;
emit I₃

qλ → Composer: evaluate closed circuit-building term; collect emits → one circuit.

9. Target theorems (fragment)

  • compile preserves denotation: ⟦compile(M)⟧Composer = ⟦M⟧qλ
  • embed then compile ≈ identity on circuits (modulo normalization)

qλ is the small call-by-value λ-calculus with three choices plus emit; Composer instructions are rich data with CP semantics; evaluation builds exactly one Composer circuit.
